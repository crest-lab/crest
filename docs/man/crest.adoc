== NAME

crest - Conformer-Rotamer Ensemble Sampling Tool based on the GFN methods

== SYNOPSIS

*crest* [_INPUT_] [_OPTIONS_]...

*crest* *--input* _file.toml_

== DESCRIPTION

CREST is a conformer/rotamer ensemble sampling tool that interfaces with
various quantum chemistry backends to explore molecular potential energy
surfaces.
It supports conformational searches, protonation/tautomer workflows, solvation
cluster growth, mass-spectral fragmentation, and various standalone utility
tasks.

The _INPUT_ argument can be a coordinate file in TM (*coord*, Bohr) or
Xmol (*\*.xyz*, Angstrom) format.
If omitted, CREST searches the working directory for a file named *coord*.
Versions 3.0 and later also accept a TOML input file either as the first
positional argument or via *--input*.

== OPTIONS

=== Run modes

*--sp*::
  Single-point energy calculation.

*--opt*, *--optimize*::
  Geometry optimization.

*--hess*, *--numhess*::
  Numerical Hessian / vibrational frequencies.

*--md*, *--dynamics*::
  Stand-alone molecular dynamics simulation.

*--v3*, *--v2i*::
  iMTD-GC iterative conformational search.
  [_default_ conformer search]

*--v4*, *--entropy*::
  iMTD-sMTD entropy-focused conformational search.

*--mdopt* [_file_]::
  Optimize every structure in an ensemble file.

*--screen* [_file_]::
  Multi-level energy screening of an ensemble.

*--protonate*::
  Automated protonation site search.

*--deprotonate*::
  Automated deprotonation site search.

*--tautomerize*::
  Automated tautomer search.

*--qcg* [_solvent_]::
  Quantum Cluster Growth solvation workflows.

*--msreact*::
  Mass-spectral fragment generator.

*--bh*, *--GMIN*::
  Basin-hopping global optimization.

*--sort*::
  Ensemble sorting via CREGEN.

=== Method selection

*-gfn2*::
  Use GFN2-xTB.
  [_default_]

*-gfn1*::
  Use GFN1-xTB.

*-gfn0*::
  Use GFN0-xTB.

*-gff*, *-gfnff*::
  Use GFN-FF.
  Bond constraints are applied automatically for GFN-FF searches.

*-gxtb*::
  Use g-xTB (requires a special build).

*-gfn2//gfnff*::
  GFN-FF trajectories with GFN2-xTB energy reweighting.

*-refine* _method_::
  Post-process conformers at a higher level of theory.

*-optlev* _level_::
  Optimization convergence level for all semiempirical calculations.
  _level_ = *crude*, *vloose*, *loose*, *normal*, *tight*, *vtight*, *extreme*.

*-dscal* [_factor_]::
  Scale the dispersion energy in MD/MTD simulations.

=== Molecular system

*-T* _int_::
  Number of CPU threads.
  If not set, read from *OMP_NUM_THREADS*.

*-chrg* _int_::
  Molecular charge.

*-uhf* _int_::
  Number of unpaired electrons (N_alpha - N_beta).

*-g* _solvent_, *-gbsa* _solvent_::
  GBSA implicit solvation.

*-alpb* _solvent_::
  ALPB implicit solvation.

*-efield* _Ex_ _Ey_ _Ez_::
  Apply a homogeneous external electric field in V/Ang along x, y, z.

*-charges* [_file_]::
  Read atomic partial charges from _file_ (default: *charges*).

=== Technical options

*--input* _file_::
  Specify a TOML input file with detailed settings.

*-xnam* _bin_::
  Path to the xtb executable (when using xtb as the backend).

*-noopt*::
  Skip pre-optimization of the input structure.

*-niceprint*::
  Show an animated progress bar during long runs.

*-dry*::
  Parse all arguments, print the resolved settings, then exit without
  running any calculation.

*-legacy*::
  Force CREST < 3.0 behaviour.

=== Constraints

The following flags apply constraints to *all* calculations made by CREST.

*-cinp* _file_::
  Read constraints from _file_ (same format as in *xtb*(1);
  formerly passed via *.constrains*).

*-cbonds* [_fc_]::
  Constrain all bonds globally (derived from topology).
  Optional force constant _fc_ in Eh.

*-cbonds_md* [_fc_]::
  Constrain all bonds during MDs/MTDs only, not optimizations.

*-nocbonds*::
  Disable automatic bond constraints.

*-fc* _float_::
  Global force constant for bond constraints.

=== Ensemble comparison and sorting (CREGEN)

*-cregen* [_file_]::
  Run CREGEN standalone to sort and deduplicate an ensemble file.

*-ewin* _real_::
  Energy window in kcal/mol.
  [_default_: *6.0* kcal/mol]

*-rthr* _real_::
  RMSD threshold in Ang.
  [_default_: *0.125* Ang]

*-ethr* _real_::
  Energy threshold in kcal/mol.
  [_default_: *0.05* kcal/mol]

*-bthr* _real_::
  Rotational constant threshold.
  [_default_: *0.01* (= 1%)]

*-pthr* _real_::
  Boltzmann population threshold (0-1).
  [_default_: *0.05*]

*-temp* _real_::
  Temperature for Boltzmann weighting in K.
  [_default_: *298.15* K]

*-topo*, *-notopo*::
  Enable or disable the topology change check.

*-ezcheck*::
  Enable E/Z double-bond isomer check.

*-heavy*::
  Use heavy-atom-only RMSD.

*-allrot*::
  Use all three rotational constants (A, B, C) for duplicate detection.

*-eqv*, *-nmr*::
  NMR nuclear equivalence analysis (requires rotamers).

*-cluster* _int_::
  PCA + k-Means clustering of the sorted ensemble.
  _int_ is the number of clusters.

*-prsc*::
  Write *scoord.** files for each conformer.

*-nowr*::
  Skip writing the sorted ensemble file.

*-osdf*::
  Write the output ensemble in SDF format in addition to XYZ.

=== Conformer search / sampling

*-v3*, *-v2i*::
  iMTD-GC (iterative MTD-GC).
  [_default_]

*-v4*, *-entropy*::
  iMTD-sMTD, specialized for entropy/free-energy sampling.

*-len* _t_[*x*], *-mdlen* _t_[*x*]::
  MD/MTD simulation length in ps.
  Append *x* to scale the default length by a factor instead.

*-tstep* _float_::
  MD integration timestep in fs.
  [_default_: *5* fs]

*-shake* _int_::
  SHAKE constraint mode: *0* = off, *1* = X-H bonds only, *2* = all bonds.
  [_default_: *1*]

*-mdtemp* _float_::
  Temperature for MTD simulations in K.

*-tnmd* _float_::
  Temperature for additional normal (unbiased) MDs in K.

*-mddump* _int_::
  Trajectory structure dump interval in fs.
  [_default_: *100* fs]

*-vbdump* _real_::
  Vbias (MTD bias) dump frequency in ps.
  [_default_: *1.0* ps]

*-nmtd* _int_::
  Number of MTD simulations per search cycle.

*-cross*, *-nocross*::
  Enable or disable the genetic structure crossing step.
  [_default_: *-cross*]

*-gcmax* _int_::
  Maximum number of structures fed into the genetic crossing.

*-nozs*::
  Disable z-matrix sorting.

*-normmd* [_n_ [_T_]]::
  Run additional unbiased MDs on the lowest-energy conformers.

*-quick*, *-squick*, *-mquick*::
  Progressively reduced search settings for fast, approximate ensembles.

*-origin*::
  Track the MTD step of origin for each conformer.
  [_default_]

*-keepdir*::
  Keep temporary working directories after the run.

*-NCI*::
  NCI cluster mode: flat-bottom wall potential and specialised MTD settings
  suited for weakly-bound complexes.

*-wscal* _float_::
  Scale the wall potential sphere radius.

*-hflip*, *-noflip*::
  Enable or disable OH proton flipping after MTD.
  [_default_: *-noflip*]

*-maxflip* _int_::
  Maximum number of OH flip attempts.
  [_default_: *1000*]

=== Thermostatistical options

*-trange* _Tmin_ _Tmax_ _Tstep_::
  Compute entropies over a temperature range.
  [_default_: *280*-*380* K in *10* K steps]

*-tread* _file_::
  Read a list of temperatures (one per line) from _file_.

*-fscal* _float_::
  Vibrational frequency scaling factor.
  [_default_: *1.0*]

*-sthr* _float_, *-rotorcut* _float_::
  Rotor cutoff in cm^-1: modes below this are treated as free rotors.
  [_default_: *25.0* cm^-1]

*-ithr* _float_::
  Imaginary mode inversion cutoff.
  [_default_: *-50.0* cm^-1]

*-ptot* _float_::
  Cumulative Boltzmann population threshold for msRRHO averaging.
  [_default_: *0.9*]

*-pcap* _int_::
  Maximum number of structures used in property (Hessian) calculations.

*-printpop*::
  Print Boltzmann populations at every temperature in the range.

*-avbhess*::
  Use a Boltzmann-averaged Hessian in the rrhoav property calculation.

=== Quantum Cluster Growth (QCG)

General usage: *crest* _solute_ *-qcg* _solvent_ [_options_]

*-grow*::
  Cluster generation run type.

*-nsolv* _int_::
  Number of solvent molecules to add.

*-fixsolute*::
  Fix the solute during cluster growth (recommended for rigid molecules;
  applied automatically for water).

*-nofix*::
  Do not fix the solute during growth (override for water).

*-nopreopt*::
  Skip pre-optimization.

*-xtbiff*::
  Use the xTB-IFF standalone program for solvent docking.

*-normdock*::
  Perform a more extensive docking step during growth.

*-maxsolv*::
  Set the convergence limit when *-nsolv* is not given.
  [_default_: *150*]

*-wscal* _float_::
  Scaling factor for the outer wall potential.

*-samerand*::
  Use the same random seed for every xTB-IFF run.

*-directed* _file_::
  Directed solvation: place solvent at positions defined in _file_.

*-fin_opt_gfn2*::
  Perform final GFN2-xTB optimization of grow and ensemble structures.

*-ensemble*::
  Ensemble generation run type.

*-qcgmtd*, *-ncimtd*::
  NCI-MTD CREST ensemble generation.
  [_default_]

*-mtd*::
  MTD for QCG ensemble generation.

*-md*::
  Normal MD for QCG ensemble search.

*-enslvl* [_method_]::
  Method for ensemble search (all GFN methods supported).

*-clustering*::
  Enable clustering for ensemble search (qcgmtd/ncimtd only).

*-esolv*::
  Reference cluster generation and solvation energy calculation.

*-gsolv*::
  Reference cluster generation and solvation free energy calculation.

*-nclus*::
  Number of clusters for reference generation.
  [_default_: *4*]

*-nocff*::
  Disable the CFF algorithm.

*-freqscal*::
  Frequency scale factor (output only).

*-freqlvl* [_method_]::
  Method for frequency computation.

=== Mass spectral fragment generator (MSReact)

General usage: *crest* _input_ *-msreact* [_options_]

*-msnoattrh*::
  Deactivate attractive potential between H atoms and LMO centers.

*-msnshifts* _int_::
  Number of optimizations with randomly shifted atom positions.
  [_default_: *0*]

*-msnshifts2* _int_::
  Same as *-msnshifts* but with bond-repulsive potential applied.
  [_default_: *0*]

*-msnbonds* _int_::
  Maximum bond distance for the repulsive potential.
  [_default_: *3*]

*-msmolbar*::
  Deduplicate fragments by molbar codes (requires *molbar* in PATH).

*-msinchi*::
  Deduplicate fragments by InChI codes (requires *obabel*(1) in PATH).

*-msnfrag* _int_::
  Number of fragments to print (random selection).

*-msiso*::
  Print only non-dissociated structures (isomers).

*-msnoiso*::
  Print only dissociated structures.

*-mslargeprint*::
  Keep all temporary files and the MSDIR directory.

*-ewin* _real_::
  Energy window for fragment sorting in kcal/mol.
  [_default_: *200.0* kcal/mol]

*-msinput* _file_::
  Read special MSReact settings from _file_.

=== Other standalone tools

*-thermo* _file_::
  Compute thermochemistry from existing Hessian data.
  Requires a *vibspectrum* file in TM format in the working directory.

*-entropy* [_T_]::
  Compute conformational entropy from an ensemble.
  Optional temperature _T_ in K.

*-sort*::
  Sort ensemble structures by energy (CREGEN).

*-symmetries*::
  Symmetry analysis of all structures in an ensemble.

*-printboltz*::
  Print Boltzmann population weights for each structure.

*-compare* _f1_ _f2_::
  Compare two ensembles _f1_ and _f2_ for structural overlap.
  Both files must share the same atom ordering.

  *-maxcomp* _int_:::
    Maximum number of conformers taken from each ensemble for comparison.
    [_default_: *10*]

*-splitfile* _file_ [_i_] [_j_]::
  Split an ensemble into per-structure directories under *SPLIT/*.
  _i_ and _j_ optionally select a range of structures.

*-rmsd* _f1_ _f2_::
  RMSD between two structures (coordinates auto-converted to Angstrom).

*-rmsdheavy* _f1_ _f2_::
  Heavy-atom RMSD between two structures.

*-protonate*::
  Automated protonation site search via LMO pi/LP-center approach.

*-deprotonate*::
  Automated deprotonation site search.

*-tautomerize*::
  Find prototropic tautomers (protonation + deprotonation).

  *-trev*:::
    Deprotonate first, then protonate (reverse order).

  *-iter* _int_:::
    Number of protonation/deprotonation cycles.
    [_default_: *2*]

*-cregen* [_file_]::
  CREGEN ensemble sorting (see also _Ensemble comparison_ above).

*-zsort*::
  Z-matrix sorting of the input coordinate file.

*-testtopo* _file_::
  Topology / bond connectivity analysis for a given file.

*-constrain* _atoms_::
  Write an example constraint file *.xcontrol.sample*.

=== TOML input files

CREST 3.0+ accepts a TOML file as a flexible alternative to CLI flags.

  crest structure.xyz --input settings.toml
  crest settings.toml   # structure path given inside the file

A minimal TOML input file:

----
input   = "struc.xyz"
runtype = "iMTD-GC"
threads = 4

[calculation]
  [[calculation.level]]
    method = "gfn2"
    chrg   = 0
    gbsa   = "h2o"
----

Key root-level settings: *input*/*structure* (coordinate file),
*runtype* (workflow), *threads* (CPU count), *preopt* (bool),
*constraints* (constraint file path).

Main blocks: *[calculation]* / *[[calculation.level]]* /
*[[calculation.constraint]]* — method, charge, solvent, geometric
constraints; *[dynamics]* / *[[dynamics.meta]]* — MD and metadynamics
settings; *[cregen]* — sorting thresholds; *[thermo]* — thermochemistry.
